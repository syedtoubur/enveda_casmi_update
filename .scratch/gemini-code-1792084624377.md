# `ms_recalibration.md` — Test-Time Forward Simulator Recalibration & Multi-Stage Re-Ranking Blueprint

**Target Competition:** Enveda CASMI 2026 — Molecule ID From Mass Spectra  
**Evaluation Metric:** Mean Reciprocal Rank @ 25 ($\text{MRR@25}$)  
**Target Hardware / Runtime Constraints:** Kaggle Offline Submission (<= 9 hours CPU/GPU runtime, MIT/Apache-2.0 commercial-compliant weights only)  
**Primary Objective:** Adapt existing **GLACIER** and **ICEBERG** forward fragmentation simulators via a two-tier domain adaptation and per-candidate test-time calibration architecture (inspired by SPARC & MARASON) to maximize **Class 2** candidate retrieval and re-ranking accuracy without triggering rank cannibalization or Kaggle runtime timeouts.

---

## 1. Competition Context & Novelty Class Stratification

All test spectra in Enveda CASMI 2026 (~1,500 spectra across ~400 molecules, acquired on a **Bruker timsTOF** instrument across positive/negative ionization modes and single or merged collision energies like `[20, 40, 60, 80] eV`) fall into one of three hidden novelty classes:

| Class | Definition | Data Availability | Pipeline Target & Strategy |
| :--- | :--- | :--- | :--- |
| **Class 1** | **In Public Spectral Libraries** | Both the true SMILES and reference MS/MS spectra exist in training libraries (`enveda-180`, `enveda-np-examples`, `pluskal_ms2`, `riken`, etc.). | Direct Spectrum-to-Spectrum matching (Spectral Entropy Similarity). |
| **Class 2** | **Known Structure, No Public Spectra** | **No public reference spectrum exists.** However, the true 2D structure exists in large chemical databases (**PubChem** or **COCONUT**). | **PRIMARY TARGET OF THIS SPEC.** Narrow down to top-$N$ (e.g., $N=80$) candidate SMILES from PubChem/COCONUT and re-rank via **Calibrated Forward Simulation (GLACIER/ICEBERG)** + **Dual Encoders (MSAlign)** + **Generative Tanimoto Probes (GLMR)**. |
| **Class 3** | **Novel Structure** | Structure does not exist in PubChem/COCONUT. Must be predicted *de novo*. | **Conformal Prediction Gate** detects high uncertainty in Class 1/2 retrieval and routes to *de novo* generation, optionally using calibrated forward simulation to filter generated candidates. |

## 2. Six Literature Advances & Their Role in This Pipeline

An audit of 2022–2026 computational mass spectrometry literature establishes six core mechanisms that must work together in the ensemble:

### 2.1 GLMR ("Generate-to-Probe" Re-Ranking)
* **Reference:** Zhang et al., AAAI 2026 (`arXiv:2511.06259`).
* **The Hazard (Rank Cannibalization):** In previous experiments (`E#25` in `EXPERIMENTS.md`), directly injecting unverified *de novo* generated SMILES into the top candidate slots displaced valid database candidates and caused a **-0.064 LB** drop.
* **The Solution:** Condition an autoregressive chemical decoder on the pre-retrieved candidate context to generate refined structures, then **discard the generated structures as direct submissions** and use them **strictly as Tanimoto similarity probes** (via RDKit Morgan Fingerprints) to re-rank the 80 valid PubChem/COCONUT database candidates.

### 2.2 MSAlign (License-Compliant Dual-Encoder Alignment)
* **Reference:** Krzakala et al., NeurIPS 2026 (`arXiv:2605.19752`), building on **DreaMS** (Bushuiev et al., *Nat. Biotechnol.* 2025, `PMC13090125`).
* **Mechanism:** Freeze the pretrained **DreaMS** spectrum encoder and a pretrained molecular language model, training only lightweight **MLP projection heads** under a candidate-window contrastive loss to align spectrum embeddings and molecular embeddings in a shared latent space.
* **CRITICAL KAGGLE LICENSE CONSTRAINT:** Do **NOT** use `MolDeBERTa` (carries a non-commercial `CC BY-NC-ND 4.0` license, which violates Kaggle winner compliance). Per Table 4 of MSAlign, use **ChemBERTa** (**MIT License**) as the frozen molecular encoder for offline Kaggle deployment.

### 2.3 SPARC & MARASON (Test-Time Forward Simulator Calibration)
* **Reference:** SPARC (Zhong et al., Sep 2026, `arXiv:2609.35649`) & MARASON (Coley Group, ICML 2025, `arXiv:2502.17874`).
* **Core Insight:** Pretrained forward simulators (Molecule $\rightarrow$ Predicted Spectrum) suffer severe **domain shift** when transferred to new instruments (Bruker timsTOF) and complex chemical domains (Natural Products).
* **Pipeline Adaptation:** Rather than replacing our existing **GLACIER** and **ICEBERG** simulators with SPARC/MARASON models, we apply the **SPARC/MARASON test-time calibration methodology** directly on top of **GLACIER** and **ICEBERG** (detailed in Sections 3 & 4).

### 2.4 MIST-CF & FIDDLE (Cross-Formula & Adduct Priors)
* **Reference:** MIST-CF (Goldman et al., 2023, `PMC12570388`) & FIDDLE (Hong et al., *Nat. Commun.* 2025).
* **Mechanism:** Score `(formula, adduct)` pairs using subformula explanation trees (76.9%–88.3% top-1 formula accuracy). Use this score as a principled **cross-formula prior** when the 80-candidate pool spans multiple possible elemental formulas or adducts.

### 2.5 Amortized Gromov-Wasserstein Optimal Transport (Graph Matching)
* **Reference:** Méndez, Krzakala, Flamary et al., Sep 2026.
* **Mechanism:** Fast neural approximation of Gromov-Wasserstein discrepancy between the **spectrum graph** (nodes = peaks, edges = neutral mass differences) and the **molecular scaffold graph** (nodes = atoms/substructures, edges = bonds), providing an orthogonal structural alignment score.

### 2.6 Conformal Prediction / Selective Prediction (Class-3 Gating)
* **Reference:** Jürgens et al. (`arXiv:2603.10950`); Rakhshaninejad et al. (*JCIM* 2026).
* **Mechanism:** Calibrate non-conformity scores on validation sets (`enveda-180` / `enveda-np-examples`) to output guaranteed prediction sets. Use the conformal set size $\vert{}\mathcal{C}_\alpha(S_{\text{query}})\vert{}$ and score entropy to gate between Class 1/2 retrieval vs. Class 3 fallback weighting.

## 3. Core Architecture: Adapting GLACIER & ICEBERG for Class 2 Re-Ranking

### 3.1 Existing Simulators in Pipeline
1. **ICEBERG:** Two-stage neural simulator (`ICEBERG-Generate` predicts fragmentation DAGs of broken substructures; `ICEBERG-Score` uses a Set Transformer to predict peak intensities).
2. **GLACIER (`arXiv:2606.29161`):** Single-stage Graphormer + DETR-style breakpoint and intensity predictor.

### 3.2 Crucial Architectural Rule: Direction of Neighbor Retrieval
When evaluating a mystery Query Spectrum $S_{\text{query}}$ against a narrowed pool of **80 Candidate SMILES** $\{C_1, C_2, \dots, C_{80}\}$:
* **DO NOT** retrieve calibration references by comparing $S_{\text{query}}$ against `enveda-180` spectra via Spectral Entropy Similarity.
* **DO** retrieve calibration references **separately for each Candidate SMILES $C_i$** by computing **2D structural Tanimoto similarity** (RDKit Morgan fingerprints, radius=2, 2048 bits) between **Candidate SMILES $C_i$** and the known structures in **`enveda-180` + `enveda-np-examples`** (matching ionization mode and adduct where possible).
* **Why:** Forward simulation takes a candidate's **known 2D molecular structure $C_i$** as input. Each of the 80 candidates may belong to a different chemical scaffold (e.g., Candidate #1 is a flavonoid, Candidate #2 is a sesquiterpene lactone). We need to know how GLACIER/ICEBERG errs on the specific structural scaffold of $C_i$ when measured on Enveda's Bruker timsTOF instrument.

## 4. Why "Two-Tier Adaptation" (Offline Global LoRA + Online Closed-Form Calibration) is Required

### 4.1 Why Per-Candidate Test-Time LoRA (Inside the 80-Candidate Loop) is Forbidden
Running gradient-based LoRA fine-tuning separately for each of the 80 candidates at test time is **architecturally rejected** for three reasons:
1. **Kaggle 9-Hour Runtime Wall:** 400–500 test queries $\times$ 80 candidates = **32,000 to 40,000 candidate evaluations**. Running even 10 steps of PyTorch backpropagation (~0.8s) 40,000 times requires **~8.9 hours**, exhausting the entire Kaggle GPU budget on a single module.
2. **Few-Shot Overfitting:** For a specific candidate $C_i$, `enveda-180` + `enveda-np-examples` will only contain **$K = 3\text{ to }10$** close structural neighbors (Tanimoto $> 0.35$). Fine-tuning 10,000–50,000 LoRA parameters via gradient descent on 5 molecules causes severe overfitting and memorization.
3. **Inter-Candidate Score Distortion:** Updating internal neural weights independently for 79 wrong candidates and 1 true candidate destroys score calibration across the 80 candidates, creating a new rank-cannibalization hazard.
