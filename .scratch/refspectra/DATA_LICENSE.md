# Data licence and attribution

The atlas data tables, source manifest, measured validation and any numerical data charts retain **Creative Commons Attribution–NonCommercial–ShareAlike 4.0 International (CC BY-NC-SA 4.0)** compilation/derivative scope. See [the licence](https://creativecommons.org/licenses/by-nc-sa/4.0/).

The source reference compilation is labelled NC-SA4. The extraction admits only records whose exact raw per-record licence string is `CC0`; that original string and complete source attribution remain in `record_attribution.jsonl`. This filter does not relicense the compilation or derivative as CC0. Preserve the compiler, MassBank contributors and individual record attribution. Source structure rows enter the derivative only through admitted full-key reference evidence.

The COCONUT numerical mass input retains the admitted prvsiyan V2 snapshot's NC-SA4 scope and COCONUT attribution. This licence grants no rights to unrelated competition training records, spectra, labels, structures or model weights.

Original readers, portable rebuild and diagram code, explanatory prose and schematic are MIT as specified by `LICENSE-CODE-MIT.txt`. Their code licence grants no rights to independently supplied or derived data. Only literal-CC0 reference rows were extracted. No competition file, membership flag, SMILES, peak array, fingerprint vector or weight file was extracted for this atlas.

The source compilation's ND exclusion is publisher-reported. This atlas does not certify every upstream licence statement or chemical structure. Retain exact source versions, hashes and raw terms when reproducing or extending it.
