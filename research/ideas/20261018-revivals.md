# Revivals 2026-10-18 (necropsy campaign `20261018-necropsy`, base V22)

Source: the 5 necropsies listed by `python research/bin/necropsy.py --list` (all on the antigravity-exploit line;
the other 18 dead ideas have no necropsy yet), `research/necropsy/dead_signals.yaml`, and the rank-only gate
(`research/harness/gate_report.md:355-379`). The gate judges by the "other" Δ, never the leak-hit Δ.

No candidate below uses a signal listed in `dead_signals.yaml`. None places a generated candidate above its parent or
at rank 1 without a measured false-alarm rate (R11). Each fix changes the mechanism, the data or the target stratum.
None changes only a threshold.

Read this first: 4 of the 5 necropsies are headroom or power nulls (90% of C2 is leak-hit, the val median is 1 covered
spectrum per molecule). So most of the expected deltas below sit under the ±0.004 LB noise floor. The ranking puts the
measured-discriminative signal with the clearest harm cause first and puts pure reach counts next, because the counts
are cheap and cannot hurt.

## 1. nl-tiebreak-r1frozen: stoichiometry/RDA score as a same-formula tie-break below rank 1

- revives: research/antigravity-exploit/nl-sim-rda
- cause: c1c2-harm. The global additive z-term inside `gl_multi` reordered across confident rank-1 calls: C1_npx Δ
  −0.0161 [−0.0283, −0.0055], 8 displaced; C2 7 displaced (research/antigravity-exploit/nl-sim-rda/necropsy.md:4-5,10,13).
- fix: a new mechanism at a new fusion site. Remove the λ-weighted z-term from `gl_multi`. After final fusion, take each
  group of candidates with the same molecular formula inside ranks 2..25 and reorder only within that group, by
  `nl_stoich_rda_score`. Rank 1 is frozen and no candidate crosses a formula boundary, so rank-1 displacement is 0 by
  construction. The target stratum moves from "all candidates" to "same-formula isomers below rank 1". This is where
  the signal was shown to discriminate (A1 same-formula pairwise win 58.5%, necropsy.md:7).
- Why this is not the dead signal: the measured-dead neutral-loss signal in `dead_signals.yaml` is a per-child,
  child-vs-parent trigger on generated candidates. This one is a within-group order over BASE pool candidates with no
  generated children, so R11 does not apply.
- Prerequisite: settle the A4 patcher inconsistency first (`b2_patch_runner_text` missing, necropsy.md:12,17). If the
  idea's build was on the E006 base, the spec must say so and port it to V22.
- falsifier (pre-registered): DEAD if C2_hard Δ ≤ 0 or C2_hard "other" Δ ≤ 0; or any non-advisory cohort's CI upper
  bound < −0.004; or rank-1 displaced > 0 on any cohort (that would be a bug, since rank 1 is frozen); or the counter
  `nl_groups_reordered` ≤ 0 on C2_hard.
- cheapest measurement: one Kaggle CPU kernel, `harness.py scorecard` on the existing dumps (C2, C1_npx, C2_hard,
  C1_xlib, pseudo_c3; C2_np advisory) via the harness kit. It needs no new data, because `nl_stoich_rda_score` was
  already computed from the dumps in the dead run.
- expected delta: C2_hard is the target. Under the old mechanism it read "other" +0.0206 (necropsy.md:8). That included
  cross-formula moves and rank-1 swaps, which are now removed. Moving the truth from rank 3 to rank 2 is worth +0.17 for
  that molecule. So my estimate is C2_hard +0.002 to +0.006 and C1/C2 about 0 ± 0.002. The LB delta is probably below
  0.004. It earns a slot only when it ships together with other non-harmful knobs, and that combination must pass the
  combination rule.

## 2. taut-upstream-rekey: canonical-IK14 side index for pool, popularity and `pc_mass` lookups

- revives: research/antigravity-exploit/tautomer-canon-unify
- cause: non-discriminative. A post-scoring canonicalization is a no-op on V22, which already canonicalizes in
  `metric_identity`; every cohort showed 0 up / 0 down (research/antigravity-exploit/tautomer-canon-unify/necropsy.md:4,7).
  The leftover key mismatch is upstream (necropsy.md:8,10), which a post-scoring knob cannot reach.
- fix: a data change at a new stratum. Build a canonical-key side index (raw IK14 → tautomer-canonical IK14) for
  `pool_meta.parquet`, popularity and `pc_mass.npy`, and query it at lookup time. No retrain. It acts only on truths
  whose raw key differs from the canonical key, which are 120 of 1745 (6.9%) per stress_result, or 10.4% per gates.md
  (necropsy.md:9).
- falsifier (pre-registered): Step 0 is a count. STOP if, summed over C2 + C2_hard + C2_np, fewer than 5 "other"
  stratum truths are missing from the pool or have no popularity hit under the raw key but are found under the
  canonical key. Step 1, only if step 0 passes, is a replay. DEAD if the "other" Δ on the mismatch subset is ≤ 0, or
  the counter `rekey_hits` is ≤ 0, or any non-advisory cohort's CI upper bound is < −0.004.
- cheapest measurement: one Kaggle CPU kernel that joins the existing dumps' truth keys with `pool_meta.parquet` and the
  popularity arrays, then reports per-cohort leak-hit/other counts and the 6.9% vs 10.4% answer. The replay runs only
  after that.
- expected delta: the upper bound is set by the touched fraction, at most 6.9-10.4% of molecules. If 1% of molecules
  gain a pool hit landing near rank 5, the gain is about 0.01 × 0.2 = +0.002. On val it stays under the noise floor.
  The hidden test is natural-product heavy, so its tautomer share may be higher. If step 1 passes, an LB probe goes on
  a written prior.md. Harm risk is near 0, because nothing changes for molecules whose keys already match.

## 3. netstoich-leakfree: the unexecuted A3(b), net votes on a rank-1-ablated / Engine-2 shortlist

- revives: research/antigravity-exploit/transductive-net-stoich
- cause: noise-level. 90% of C2 is leak-hit (359 of 400), so the rank-2..10 voter had nothing to lift. The result was
  an exact null, CI [0, 0], with 2 molecules moved and only 2 A2 pairs evaluated
  (research/antigravity-exploit/transductive-net-stoich/necropsy.md:6,9,10,13).
- fix: a change of target stratum. Score the stoichiometry-filtered network votes (edge truthfulness 71.1% vs 44.4% raw,
  necropsy.md:11) on the leak-free Engine-2 top-25 shortlist, where truths genuinely sit at ranks 2-10. The
  pre-registered A3(b) was never run (necropsy.md:12,15). The votes themselves are unchanged and are now tested where
  headroom exists.
- falsifier (pre-registered): STOP as underpowered (no verdict, no LB slot) if fewer than 30 molecules have the truth in
  ranks 2-10 and at least 1 incident stoichiometry edge. Otherwise DEAD if the MRR Δ is ≤ 0, or if
  n_decoy_beaten_truth ≥ n_truth_beaten_decoy, or if `net_vote_moved_mols` is ≤ 0.
- cheapest measurement: one Kaggle CPU kernel on the existing dumps. Count first; run the replay only if n ≥ 30.
- expected delta: val has only 9 stoichiometry edges and 16 network molecules (necropsy.md:10). The power check will
  probably STOP it, and even a pass is far below 0.004 on val. Its value is the discrimination number. If that number
  is positive, the necropsy's third path applies: an LB probe on prior.md with counter `net_stoich_edges` > 0
  (necropsy.md:17), because network density on the hidden test cannot be judged offline.

## 4. xformula-c3-hardcheck: formula-group promotion on the pseudo_c3 stratum, gated by a hard physical check

- revives: research/antigravity-exploit/cross-formula-cluster
- cause: c1c2-harm. Every promotion on a leak-hit molecule was false: C2 Δ −0.0265, leak-hit −0.0294 vs other −0.0007,
  10 displaced. The headroom is K3 n_wrong_f1 = 0 on the "other" stratum
  (research/antigravity-exploit/cross-formula-cluster/necropsy.md:5-6,8,11).
- fix: a new trigger plus a new stratum. (a) Fire only when the rank-1 formula fails a hard physical check: timsTOF
  |ppm − 1.45| > 3σ, or an adduct that is impossible for that formula. The old soft score-margin trigger is not used.
  (b) Target pseudo_c3, where `|gen` formula groups have no BASE memorization pinning the formula, so a wrong-formula
  rank 1 can exist (necropsy.md:13-14). The formula composite itself is discriminative (A1 86.9%, necropsy.md:9) and is
  not in `dead_signals.yaml`.
- R11 guard: the promoted group's new rank 1 must be its best BASE candidate, never a `|gen` child, unless a later
  measurement shows the hard check's C1/C2 fire rate ≤ 4.5%.
- falsifier (pre-registered): STOP if, on pseudo_c3 top-10, fewer than 6 molecules (1% of 600) have a wrong rank-1
  formula AND fail the hard check. DEAD if the hard check fires on more than 4.5% of C1/C2 molecules whose rank 1 is
  the truth. In the replay: DEAD if pseudo_c3 "other" Δ is ≤ 0, or displaced is > 1% of 600, or any non-advisory C1/C2
  CI upper bound is < −0.004.
- cheapest measurement: Kaggle CPU kernel. Count n_wrong_f1 with the hard-check flag on the pseudo_c3 dump, and the fire
  rate on the C1/C2 dumps. Replay only if both pass.
- expected delta: pseudo_c3 showed only 1 displaced under the old trigger (necropsy.md:14), so harm risk is low, but the
  headroom count is unknown. On the LB, C3 is about a third of the class weight and pool reach caps it, so I expect
  under +0.003 on the LB.

## 5. ce-band-proxy: CE-band reweighting with a CE proxy recomputed from `ms2_*` arrays

- revives: research/antigravity-exploit/20261017-per-spectrum-dump
- cause: non-discriminative. Val dumps lack the signal: BPI is present on 0.000 of covered spectra and finite CE on
  0.358, vs 1.000 / 1.000 on test (research/antigravity-exploit/20261017-per-spectrum-dump/necropsy.md:4-5).
- fix: a data change. Recompute an energy proxy per spectrum (TIC, peak count, precursor-survival fraction) from the val
  `ms2_*` arrays. Validate it against native CE on the spectra that have finite CE, then dump per-spectrum similarities
  keyed by the proxy (necropsy.md:10).
- falsifier (pre-registered): STOP if Spearman ρ between the proxy and native CE is < 0.6 on finite-CE covered
  spectra, or if fewer than 50 val molecules have ≥ 2 covered spectra (the val median is 1, necropsy.md:11). Without
  ≥ 2 spectra, per-molecule reweighting is the identity.
- cheapest measurement: a Kaggle CPU kernel that reads `ms2_*` and reports ρ and the multi-spectrum molecule count. No
  replay.
- expected delta: offline it is almost certainly unmeasurable (median 1 spectrum per molecule). I list it so the counts
  get recorded once and the instrument family is closed or opened on numbers. LB expectation: unknown. It goes to the
  LB only through a prior.md if both counts pass.

## Combinations: none proposed

I see no pair that has numbers on distinct strata yet. #1 acts on same-formula truths already in ranks 2-25 (C2_hard
"other"). #2 acts on truths missing from the pool under the raw key. The two are disjoint by construction, since a
pool miss cannot sit at ranks 2-25, but #2's count is unmeasured. Once #2's step 0 returns its "other" count, a #1+#2
combination may be written with `combines:` citing both counts. #3 and #1 both act on "truth in ranks 2-10, other", the
same stratum, so that pair is dropped. The cross-formula necropsy reaches the same conclusion for a3-formula-eif and
e180-drop (research/antigravity-exploit/cross-formula-cluster/necropsy.md:17-18).
