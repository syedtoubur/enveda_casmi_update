## P1: a pre-registered "reach > 0" spike rule must be written on a set that can come out zero
- action: add
- kind: lesson
- target: LESSONS.md
- decision: promoted 2026-10-14 (L48)
### Text
A pre-registered build rule of the form "count X on cohort P, build iff count > 0" is not a gate when cohort P is defined as "the structures X would add" (cohort P = NP-table compounds missing from the pool) and the window condition is evaluated on the truth's own re-centred mass. The first two conditions hold by construction and the residual is 0 ppm, so the count is > 0 whatever the data say. Before pre-registering a reach spike, name the population it runs on (spectra, with truths a hidden test could share) and state what count would kill the idea. A rule that cannot return zero measures that the structures exist, not that any test truth is one of them. If every cohort with real spectra gives 0 by construction (val truths are train structures, L07), the ceiling is UNMEASURED and the idea needs a recorded `--override`, not a spike pass.
### Reasoning
The campaign's pre-registered block said "Build (heavy path) iff that count > 0". The spike returned 4,748 structures (2,629 outside the v2-pool too), so the rule was met, while the brief's other bar ("heavy-path ideas dead unless a measured ceiling > 0") was not: all 1,390 val truths gave reach 0, also by construction. The two bars disagreed and the spec had to put the choice to the human in questions.md Q1. The human closed the idea as UNMEASURED-dead after spec, so the cost was one spec cycle and no build, but the pre-registration should have been able to kill the idea itself. This is the same shape as L39 (a gate no idea could fail) and L44 (reach sized without the split that decides it), applied to a rule written before measurement. A code rule is not offered: whether a population can return zero needs judgment per idea. The loop-code gap (ENGINE2_NPX is not listed in `families.engine2_model`, so R08 and the scorecard do not call it BLIND) is already a proposal in questions.md Q2 and is not repeated here.
